Calculadora en Java

Este es un programa hecho en Java para la clase de Programación 1.

El programa funciona como una calculadora básica que permite:

- Sumar
- Restar
- Multiplicar
- Dividir

El usuario selecciona la opción desde un menú y luego ingresa los números que desea calcular.

En este proyecto se utilizaron:

- Clases y objetos
- Métodos
- Encapsulamiento
- switch
- do-while
- JavaDoc

El programa fue desarrollado en Apache NetBeans.
