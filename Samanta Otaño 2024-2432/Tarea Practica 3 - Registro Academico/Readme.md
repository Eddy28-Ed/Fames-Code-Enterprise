Registro Académico - Java Swing

Descripción
Aplicación de escritorio en Java Swing que permite capturar datos personales de un estudiante y 
sus calificaciones, calcular la nota final y determinar si está aprobado o reprobado.

Funcionalidades
- Captura de datos personales (nombre, matrícula, carrera)
- Registro de calificaciones:
  - Prácticas (0-40)
  - Parciales (0-20)
  - Asignaciones (0-20)
  - Examen Final (0-20)
- Cálculo automático de nota final
- Mensaje de:
  - APROBADO (≥60)
  - REPROBADO (<60)
- Validación de datos
- Advertencia si la nota es mayor a 90
- Botón para limpiar campos

Tecnologías
- Java
- Java Swing
- Programación Orientada a Objetos

Estructura
- Estudiante.java (lógica)
- RegistroAcademicoGUI.java (interfaz)
- Main.java (ejecución)
