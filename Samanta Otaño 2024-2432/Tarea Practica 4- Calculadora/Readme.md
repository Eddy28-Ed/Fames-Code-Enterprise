Calculadora Extendida con Java Swing

Descripción
Aplicación de escritorio que funciona como calculadora extendida, 
incluyendo operaciones matemáticas básicas, raíz cuadrada, exponente 
y conversión de temperatura.

Funcionalidades
- Operaciones básicas:
  - Suma
  - Resta
  - Multiplicación
  - División
- Validación de división por cero
- Cálculo de:
  - Raíz cuadrada
  - Exponente
- Conversión de temperatura:
  - Celsius a Fahrenheit
  - Fahrenheit a Celsius
- Interfaz gráfica amigable

Tecnologías
- Java
- Java Swing

Estructura
- Calculadora.java
- ConversorTemperatura.java
- RaizExponente.java
