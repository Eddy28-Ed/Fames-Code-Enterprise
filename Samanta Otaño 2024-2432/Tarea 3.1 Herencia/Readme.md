# Tarea 3.1 - Herencia y Encapsulación

## Descripción
Proyecto en Java que implementa los conceptos de encapsulación y herencia mediante 
la creación de una clase base AutoMovil y una clase derivada HondaCivic.

Funcionalidades
- Uso de atributos privados (encapsulación)
- Implementación de getters y setters
- Herencia mediante extends
- Sobrescritura de métodos (@Override)
- Prueba de funcionamiento en clase Main

Tecnologías
- Java
- Programación Orientada a Objetos

Estructura
- AutoMovil.java
- HondaCivic.java
- Main.java
